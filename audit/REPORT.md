## 2. 총평과 점수

### 강점 2개
1. **연출의 완성도가 높다.** 스크롤 라이브러리 없이 구역 단위 이동·가로 트랙·WebGL 엔딩까지 자체 구현했고, `prefers-reduced-motion` 에서는 문서 높이를 30,822→14,350px 로 줄이고 애니메이션을 0개로 떨어뜨리는 대체 경로까지 갖췄다(실측). 이 규모의 사이트에서 드문 수준이다.
2. **실패 경로를 진지하게 다뤘다.** 자바스크립트가 꺼져도 ABOUT 본문과 문의 주소가 보이고, 장식 이미지가 깨지면 자리를 비우며, WebGL 이 실패하면 대체 화면으로 넘어간다. 코드 주석이 '왜 이렇게 했는지'를 실측값과 함께 남겨 두어 감사 자체가 수월했다.

### 가장 큰 약점 3개
1. **사실과 다른 표시가 세 군데 있었다.** 존재하지 않는 수탁사를 적은 개인정보 처리방침, 보내지 않았는데 "보냈습니다"라고 알리는 문의 완료 화면, 지어낸 실적 44건. 셋 다 배포 시 신뢰·법적 위험이었고 이번에 고쳤다.
2. **첫 로드 37.13MB.** 18.6MB 를 줄였지만 여전히 크다. 원인은 1254×1254 PNG 캐릭터 그림(장당 1.0~1.8MB)이 66~430px 로 표시되는 것 — 재인코딩은 화질 판단이 필요해 보류(Q-11).
3. **마지막 12,150px(전체의 39%)이 다른 브랜드의 세계관이다.** ENDING 게임룸의 주인공이 시바견이 아니라 옛 TVA 의 CRT 모니터 마스코트이고, 배경은 공작기계 작업장이며, The Sims 의 플럼밥이 그대로 떠 있다.

### 4.3 “유지”로 보이는 항목의 실제 내용

숫자가 그대로인 세 가지는 **고치지 않은 것이 아니라, 애초에 결함이 아니었거나 도구의 한계**입니다.

- **T8 숨은 포커스 1건** = 스팸 방지용 빈 칸(`input.hp`). `left:-9999px` + `opacity:0` + `tabindex="-1"` +
  `aria-hidden="true"` 라 **Tab 으로 닿지 않습니다.** 도구는 `aria-hidden` 안에 포커스 가능한 요소가 있다는 사실만 봅니다.
  이번에 붙어 있던 `aria-label="스팸 방지용 빈 칸"`(숨은 칸에 이름을 주는 모순)은 제거했습니다(#M03).
- **T11 대비 실패 7건 중 5건**은 편지지가 **사진 위**에 놓여 도구가 조상 요소의 배경색으로 계산한 것입니다.
  캡처로 실제 색을 확인했습니다(어두운 글자 / 밝은 종이). 나머지 2건은 ①첫 칸에서 `disabled` 인 `←`(WCAG 예외)
  ②`mix-blend-mode:difference` 라 계산이 성립하지 않는 낙하 구간 `SCROLL` 안내(#D02, 보류).
- **T4 “24~44px” 2건**은 위의 `input.hp` 와 **정확히 24×24 인 동의 체크박스**입니다. 24×24 는 WCAG 2.2 AA
  2.5.8 기준을 **충족**합니다(도구는 44px 권장선 미만이면 ⚠️ 를 답니다). 기준 미달(`❌ 24px 미만`)은 1건 → 0건.

### 6.2 이번 수정이 스스로 만든 회귀 (숨기지 않고 적습니다)

`#N01`(같은 그림을 여러 `?v=` 로 받는 문제)을 고치면서 `journey.js` 의 템플릿 문자열

**`?v=eternal-beam-r51eternal-beam-r51` 이라는 존재하지 않는 판 번호로 6곳이 요청**되고 있었습니다.
정적 검사(`qa-check.mjs`)는 템플릿 안이라 못 잡았고, **실행 중 요청을 모으는 검사(`verify2.mjs`)에서 드러났습니다.**
`?v=${GOYA_V}` 로 되돌리고, 같은 종류의 실수를 다음에도 잡도록 두 가지를 남겼습니다.
- `qa-check.mjs [2]` 를 **CSS·JS 모듈까지** 보도록 확장 (정적)
- `audit/scripts/verify2.mjs` 의 `중복주소` 검사 (실행 중)

**두 번째 회귀 — #N02(배경 영상)의 허점 두 개.** 재감사에서 실제로 영상이 도는지 확인해 보니:
1. 통로 한가운데에 **가만히 서 있으면 영상이 첫 프레임에 멈춰** 있었습니다.
   `is-live` 를 붙이는 관찰자가 `draw()` 보다 늦게 불리면 재생 판단이 다음 스크롤까지 미뤄졌기 때문입니다
   (실측: y=1400 에서 2.2초 뒤에도 `paused · t=0`). → 관찰자가 켜질 때 한 번 다시 그리게 했습니다.
2. 그런데 그것만 고치자 **10MB 영상이 첫 로드로 되돌아왔습니다.** `is-live` 는 합성 레이어를 미리 올리려고
   앞뒤 60% 를 더 보기 때문에 **첫 화면에서 이미 켜져 있었습니다.**
   → 재생용으로 `rootMargin:0` 짜리 관찰자를 따로 두고, `preload` 도 `metadata` → **`none`** 으로 낮췄습니다.

두 번 다 **"고쳤다고 적은 것이 실제로 그렇게 동작하는지"를 다시 재 보고** 찾았습니다.

### 13.2 통일안

**간격 — 4px 배수 8단계.** `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64`
지금 38개 중 `34.56px`·`37.44px` 같은 값은 `vw` 계산의 부산물입니다. 뷰포트 연동이 필요한 곳만
`clamp(16px, 2.4vw, 32px)` 처럼 **의도를 적은 한 줄**로 바꾸면 나머지는 8단계로 흡수됩니다.

```css
:root{ --s-1:4px; --s-2:8px; --s-3:12px; --s-4:16px; --s-5:24px; --s-6:32px; --s-7:48px; --s-8:64px; }
```

**타입 스케일 — 7단계.** 지금 28개는 `px` 와 `vw` 가 섞여 생긴 것입니다.
본문은 16px 을 바닥으로 두고(지금 모바일 12~13px 은 #C05), 표제만 뷰포트 연동으로 둡니다.

```css
:root{
  --t-caption:11px;  --t-small:13px;  --t-body:16px;   --t-lead:20px;
  --t-h3:clamp(28px,3.2vw,40px);  --t-h2:clamp(40px,6vw,72px);  --t-display:clamp(64px,12vw,180px);
}
```

**색 — 지금 쓰는 값 그대로, 이름만 정리.** 새 색을 만들자는 것이 아닙니다.
`--cobalt` 와 `--beam-gold` 가 **같은 `#c8a15e`** 이고, `--print-blue`·`--deep-blue` 는 이름이 파랑인데 값은 금갈색입니다(#Q02).

```css
:root{
  --ink:#171923; --ink-muted:#55565b; --ink-faint:#6f7077;   /* 흰 바 위 4.93:1 */
  --paper:#fff;  --cream:#f6f2e8;     --line:#d6d7db;
  --gold:#c8a15e;  --gold-deep:#b4aa89;  --night:#0d0d0f;
}
```
→ `--cobalt`·`--beam-gold` 는 `--gold` 의 별칭으로 한 번만 남기고, 이름과 값이 어긋난 두 변수는 제거.

**radius·그림자 — 3단계씩.** 유기 곡선(`49% 51% 48% 52% / …`)은 연출용이므로 그대로 두고, 상자 UI 만 통일합니다.
```css
:root{ --r-0:0; --r-1:2px; --r-pill:999px;
       --sh-1:0 1px 2px rgb(23 25 35/.08); --sh-2:0 8px 24px rgb(23 25 35/.18); --sh-glow:0 0 10px var(--gold); }
```

**easing·duration — 이미 거의 정리되어 있습니다.** `cubic-bezier(.16,1,.3,1)` 이 사실상 표준입니다.
```css
:root{ --ease:cubic-bezier(.16,1,.3,1); --d-fast:.16s; --d-base:.3s; --d-slow:.55s; }
```

**z-index — 6층.** 지금 24개 값이 파일 7개에 흩어져 있어, 이번 감사에서 실제로 사고가 났습니다
(#B04 1차 시도: `.studio-track` 을 3→11 로 올렸다가 골드 칸 그라디언트가 캐릭터를 통째로 지웠고 되돌렸습니다).
```css
:root{ --z-bg:0; --z-content:10; --z-actor:20; --z-nav:30; --z-overlay:40; --z-dialog:90; }
```

**브레이크포인트 — 지금 쓰는 값 그대로 이름만.** `360 · 760 · 1024 · 1440`.
이번에 `max-width:360px`(로고 88px), `max-width:760px`(모바일 전체)을 실제로 썼고,
짧은 화면용 `max-height:920/790/690px` 세 단은 **높이 기준**이라 별도 축으로 둡니다.

2. **나중**: 타입 스케일은 모바일 본문 크기 결정(#C05)과 함께.
