# ORIGINAL 이미지 교체

1. 이 폴더에 `01.webp`, `02.webp`, `03.webp`, `04.webp` 이미지를 저장합니다. JPG/PNG도 가능합니다.
2. 프로젝트 루트 `original-works.js`에서 원하는 칸의 `image: null`을 `image: 'assets/original-works/01.webp'`처럼 바꿉니다.
3. 같은 항목의 `title`(작품명), `alt`(이미지 설명)를 수정하고 새로고침합니다.

왼쪽부터 collection-01~04입니다. 각 영역은 독립적으로 교체됩니다. null이면 현재 선택된 그림을 유지합니다. 권장 비율은 세로 A2 420:594입니다. 다른 비율은 영역을 꽉 채우며 중앙 기준으로 잘립니다. 위쪽을 기준으로 하려면 position을 xMidYMin, 아래쪽은 xMidYMax로 바꿉니다. 클릭 상세에서도 같은 이미지를 보여줍니다.

배경/상단바/기울기/클릭 코드를 수정할 필요는 없습니다. 관리 화면이나 업로드 서버를 추가한 방식은 아니며 프로젝트 파일로 관리합니다.
