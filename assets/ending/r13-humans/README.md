# R13 licensed human models

These characters come from Quaternius's Ultimate Modular Characters collection:

- Official pack page: https://quaternius.com/packs/ultimatemodularcharacters.html
- Public source mirror: https://github.com/agentkaerf/FreeModels
- Mirror revision used: `db3df04d1e4714298a09510b26fb6de6645138a2`

The selected embedded glTF files were copied without model edits:

| Local file | Mirror source at the pinned revision |
|---|---|
| `man-casual.gltf` | `Ultimate Modular Men- Feb 2022/Individual Characters/glTF/Casual_2.gltf` |
| `man-hoodie.gltf` | `Ultimate Modular Men- Feb 2022/Individual Characters/glTF/Casual_Hoodie.gltf` |
| `woman-casual.gltf` | `Ultimate Modular Women - April 2022/Individual Characters/glTF/Casual.gltf` |
| `woman-formal.gltf` | `Ultimate Modular Women - April 2022/Individual Characters/glTF/Formal.gltf` |

Quaternius released both packs under CC0 1.0 Universal. The source license texts are retained verbatim as `LICENSE-MEN.txt` and `LICENSE-WOMEN.txt`.

The files include skeletons and authored animation clips. Runtime smoothing, muted material response, deterministic animation sampling, scale normalization, and scene placement are implemented in `ending-humans-r13.js`.
