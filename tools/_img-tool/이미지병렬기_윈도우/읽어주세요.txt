이미지 병렬기 - 윈도우판
=======================================

한 번의 프롬프트로 서로 다른 그림 여러 장을 동시에 만드는 도구입니다.
맥 앱과 같은 엔진(gti)을 그대로 씁니다.


[ 순서 ]

1. 1_처음에_한번만.bat  두 번 누르기   (처음 한 번만)
2. 로그인 파일 놓기                    (아래 참고, 이것도 한 번만)
3. 2_실행.bat  두 번 누르기            (쓸 때마다)


[ 2번 - 로그인 파일 ]

이 도구는 새로 결제하지 않습니다.
이미 쓰고 계신 ChatGPT 구독의 로그인 정보를 빌려 씁니다.
그래서 로그인 파일 하나가 아래 자리에 있어야 합니다.

    C:\Users\(내이름)\.codex\auth.json

두 가지 방법 중 하나를 쓰시면 됩니다.

  방법 A - 윈도우에서 직접 로그인
    명령 프롬프트에서   npm install -g @openai/codex
    그다음              codex login
    로그인하면 위 파일이 저절로 생깁니다.

  방법 B - 맥에 있는 파일을 옮기기
    맥의  ~/.codex/auth.json  을 위 자리로 복사합니다.
    ※ 이 파일은 열쇠입니다. 남에게 보내거나 공유 폴더에 두지 마세요.


[ 쓰는 법 ]

창이 뜨면 넣을 것은 사실상 두 개입니다.

  - 프롬프트   : 만들고 싶은 그림을 글로. 한글로 써도 됩니다.
  - 개수       : 1 ~ 50장

선택으로 참고 이미지를 끌어다 놓을 수 있고,
기획서(docx / pptx / pdf)를 넣으면 글을 뽑아서 씁니다.

동시에 20장까지 한꺼번에 만들고, 먼저 끝난 것부터 화면에 뜹니다.
마음에 드는 것을 고른 뒤 반드시 [저장]을 누르세요.
누르지 않으면 임시 폴더에 있다가 사라집니다.


[ 안 될 때 ]

"gti 라이브러리를 찾을 수 없습니다"
  -> gti 폴더가 이 파일들과 같은 자리에 있어야 합니다. 옮기지 마세요.

그림이 한 장도 안 나오고 오류만 난다
  -> 모델 이름이 안 맞는 경우입니다.
     2_실행.bat 을 메모장으로 열어
     set CODEX_IMAGEGEN_MODEL=gpt-5.6-sol
     이 줄의 이름을 바꿔 보세요.
     맥의  ~/.codex/config.toml  안 model 값과 같아야 합니다.

로그인 파일이 없다고 나온다
  -> 위 [2번] 을 다시 보세요.


[ 정직하게 적어 둡니다 ]

  맥 앱에는 그 뒤에 붙은 기능(고정 자산, 변주 모드, 최대 1000장)이 더 있는데,
  그 판의 원본 코드가 남아 있지 않아 여기엔 못 넣었습니다.
  그림을 만드는 엔진은 맥 앱과 같은 것입니다.

- 윈도우에서 실제로 돌려보지는 못했습니다.
  코드에 맥 전용 부분이 없다는 것까지는 확인했습니다.
  안 되면 화면에 나온 글을 그대로 알려주세요. 바로 고치겠습니다.
